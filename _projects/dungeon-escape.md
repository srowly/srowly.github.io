*This project is currently in development. More to come.*

Dungeon Escape is a first-person 3D dungeon crawler built in Unreal Engine C++, featuring a series of interactive environmental puzzles across a dark, atmospheric dungeon setting. This is the next project I'm following from the Udemy Course I bought a course on Udemy, Unreal Engine 5 C++ Game Development.

I'm really enjoying working on this project. I love the **Might and Magic** game series. Recreating a piece of that in Unreal is the goal.

Following Obstacle Assault, this is the project where the foundations move beyond tutorial scope: custom interaction systems, environmental storytelling, first-person mechanics, and puzzle design that actually works. Development has started. Updates will follow here.
